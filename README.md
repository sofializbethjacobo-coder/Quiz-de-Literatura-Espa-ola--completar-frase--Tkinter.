# Quiz-de-Literatura-Espa-ola--completar-frase--Tkinter.
Juego interactivo en Python con Tkinter donde completas 5 frases aleatorias de literatura española cargadas desde un CSV, eligiendo entre escribir la palabra (10 pts) o seleccionarla de una lista con opciones (5 pts) para ver tu puntaje final y aciertos.
